### 2. The 65 files — restored rather than committed

The churn was **52 mode-only changes (644 → 755)**, every one on documentation, CI config or
metadata (`.md`, `.yml`, `.json`, `.cff`, `.lock`) with **no shell or Python script among

have recorded a mistake as intent. All restored.

**A filter bug caught mid-task, worth remembering:** selecting mode-only files by
`git diff --numstat` fields being `0/0` silently misses binaries, which report `-` instead.

`hyperchess-live-stream/broadcast/assets/ambient.mp3` — whose content md5 (`8bdd75d3`) is
identical to the committed blob, only its mode had moved. Restored those too.

  three repositories. Keep them in step.
- **The umbrella tracks workspace-level material only** — `index.md`, `docs/`, `.claude/`,
  `assets/`, `scripts/`. Sub-project source trees and the nested repositories stay untracked
  pending a deliberate structure decision.

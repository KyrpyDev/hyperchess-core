## Blocked — four items

### 1. crates.io: unverified email  *(account action)*
`cargo publish -p hyperchess-eval` reached upload and was rejected:
`400 Bad Request: A verified email address is required to publish crates to crates.io.`
Fix at <https://crates.io/settings/profile>. The token itself is valid.

### 2. npm: 2FA  *(account action)*
`pnpm publish --access public` returned `403 Forbidden — Two-factor authentication or
granular access token with bypass 2fa enabled is required`. `npm whoami` succeeds
(`kyrpydev`), so the token authenticates but is a classic/automation token. Fix: a
**Granular Access Token** with read-write on the `@hyperchess` scope and 2FA bypass, or an
interactive OTP publish.

### 3. `hyperchess-driver` cannot be published  *(design decision)*
Proven by dry run: `all dependencies must have a version requirement specified when
publishing. dependency 'cust' does not specify a version`.
`crates/hyperchess-driver/Cargo.toml:45` carries
`cust = { path = "/projects/github/rust-cuda/crates/cust", optional = true }` — an absolute
local path to an unpublished crate; line 27 has the same issue with `hyperchess-search-cuda`
(itself `publish = false`). Being behind the optional `cuda` feature does not help — cargo
validates all dependencies regardless of gating. The other four crates are ready.

### 4. `docs-overhaul-wip` cannot be pushed to GitHub  *(pre-existing)*
It has cargo build artifacts committed into it — several 110-133 MB binaries under
`.claude/worktrees/hyperchess-builds/` — exceeding GitHub's 100 MB hard limit. Left local
rather than rewriting another session's WIP history.

## Decisions of record

- **All earlier decisions of record remain binding.**
- **The public home is now `https://github.com/KyrpyDev/hyperchess-core`.** The
  `hyperchessdev` account no longer hosts this project.
- **Always rebuild the npm packages immediately before publishing.** Their `dist/` is
  gitignored and goes stale silently; four of five were stale this session.
- **npm publishing must use `pnpm`, not `npm`.** The packages declare inter-package
  dependencies as `workspace:*`, which pnpm rewrites to real version ranges at publish time
  and npm does not — `npm publish` would ship broken manifests.
- **Fix URLs before the first publish of any version.** crates.io metadata is immutable per
  version; there is no post-hoc correction.
- **`hyperchess-driver` stays unpublished** until the `cuda` feature's local path
  dependencies are resolved one way or another.
